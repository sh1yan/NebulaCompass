文档说明

平台简介

星云罗盘 - 资产测绘平台（NebulaCompass）是一款用于内外网资产探测和端口扫描的工具。它集成了 nmap 和 masscan 两款经典网络扫描工具，提供完整的存活探测、端口扫描和服务识别能力。

平台支持多种扫描模式，包括：全套扫描、存活探测、端口扫描、服务识别以及 Nmap 端口扫描，覆盖从资产发现到服务识别全流程。

配套工具说明

本平台依赖 nmap 和 masscan 两个外部工具来完成扫描任务。以下是如何获取和安装这两个工具的详细说明。

Nmap

Nmap（Network Mapper）是一个开源的网络探测和安全审计工具。本平台使用它进行主机存活探测（Ping扫描）和服务版本识别。

下载地址

⭐ 官网下载 📦 所有版本

官网提供 Windows、macOS、Linux 各平台的安装包和源码。

安装方式

Windows:

  • 从官网下载 nmap-7.95-setup.exe 安装包，双击安装即可
  • 安装完成后默认路径为 C:\Program Files (x86)\Nmap\nmap.exe
  • 安装程序会自动将 nmap 添加到系统 PATH

macOS:

# 使用 Homebrew 安装（推荐）
brew install nmap

# 或从官网下载 .dmg 安装包手动安装

Linux (Debian/Ubuntu):

sudo apt update
sudo apt install nmap -y

Linux (CentOS/RHEL):

sudo yum install nmap -y

从源码编译:

# 下载源码
wget https://nmap.org/dist/nmap-7.95.tar.bz2
tar jxvf nmap-7.95.tar.bz2
cd nmap-7.95

# 编译安装
./configure
make -j$(nproc)
sudo make install

编译依赖：需要安装 gcc、make、openssl-dev 等开发工具包。

Masscan

Masscan 是一款高速端口扫描器，号称"最快的互联网端口扫描器"。本平台使用它进行大规模端口扫描，利用其高速扫描能力快速发现开放端口。

下载地址

⭐ GitHub 项目 📦 Release 页面

安装方式

macOS:

# 使用 Homebrew 安装（推荐）
brew install masscan

Linux (Debian/Ubuntu):

sudo apt update
sudo apt install masscan -y

从源码编译（推荐，获取最新版本）：

# 克隆源码
git clone https://github.com/robertdavidgraham/masscan.git
cd masscan

# 编译（使用 make 即可，无需 configure）
make -j$(nproc)

# 安装到系统（可选）
sudo make install

# 如果不安装到系统，可以直接使用当前目录下的 ./bin/masscan
./bin/masscan --help

Masscan 的编译非常简单，只需要 gcc 和 make 即可，没有额外的依赖库。编译完成后，可执行文件在 bin/masscan。

Windows:

  • Masscan 主要面向 Linux/macOS，Windows 上可以：
  • 使用 WSL（Windows Subsystem for Linux） 在 Linux 子系统中编译使用
  • 或在 Cygwin/MSYS2 环境中编译

使用 w64devkit 编译（推荐 Windows 用户）：

如果没有安装编译环境，可以使用 w64devkit 工具进行编译。w64devkit 是一个面向 Windows 的便携式 C/C++ 开发工具包，内含 gcc、make 等编译工具，无需额外安装 Visual Studio 或 MinGW。

# 1. 下载 w64devkit
# 访问 https://github.com/skeeto/w64devkit/releases
# 下载 w64devkit-x.x.x-x.x.x.zip 并解压到任意目录

# 2. 进入解压后的目录，运行 w64devkit.exe 打开命令行环境
# 该环境已自动配置好 gcc、make 等编译工具
w64devkit.exe

# 3. 在命令行中编译 masscan
git clone https://github.com/robertdavidgraham/masscan.git
cd masscan
make -j4

# 4. 编译完成后，可执行文件在 bin/masscan.exe
ls -la bin/masscan.exe

编译完成后，将 bin/masscan.exe 的路径填写到平台的"系统设置"页面的"Masscan 路径"中即可。

工具验证

安装完成后，建议在系统终端中验证工具是否可以正常使用：

# 验证 nmap
nmap --version

# 验证 masscan
masscan --version

如果以上命令可以正常输出版本信息，说明工具已正确安装并添加到系统 PATH 中。然后在平台的"系统设置"页面中，分别填入工具路径即可（如果已配置系统 PATH，填入工具名即可，如 nmap 或 masscan）。

设置页面中，填入路径后点击"验证"按钮，平台会自动检查路径是否正确。

扫描模式说明

每种模式只执行该模式定义的动作，不会串跑其它阶段：

  • 全套扫描 - 存活探测（nmap -sn）→ 端口扫描（masscan）→ 服务识别（nmap -sV）。最完整的流程。
  • 存活探测 - 仅执行 nmap -sn 存活探测，不端口扫描、不服务识别；端口范围不生效。
  • 端口扫描 - 仅执行 masscan 端口扫描，不做存活探测、不做服务识别（目标直接交给 masscan）。
  • 服务识别 - 仅执行 nmap -sV，不做存活探测、不做端口扫描。只扫描目标里写明的端口：目标必须写成 IP:端口（如 10.0.0.1:22、example.com:443），该模式下没有「端口范围 / 预置端口列表」，缺端口的目标会在创建时被拦下并提示修改。
  • Nmap端口扫描 - 仅用 nmap 做端口扫描（-sS，非 root 自动退化为 -sT），不做服务识别。

端口范围与预置端口列表

  • 新建任务时既支持自定义端口，也支持多选预置端口列表：常见 100 端口、常见 WEB 端口、常见约 1200 端口、数据库与 MQ 端口、常见 UDP 端口。
  • 预置端口列表按「常用 / 专项」分组展示，右上角实时显示「已选 N 项 · 约 X 个端口」，并提供全选 / 清空一键操作。
  • 勾选的预置列表会与自定义端口自动合并去重，弹窗底部会实时显示"最终端口规约"和端口数量。
  • 语法：TCP 直接写 80,443,8000-8100；UDP 加前缀 U:，例如 80,443,U:53,161。选到 UDP 预置时，nmap 会自动加 -sU，masscan 会自动使用 U: 写法。

进度显示与状态同步

  • 端口扫描阶段（masscan）会把 masscan 自带的进度百分比、预估剩余时间（remaining）与速率（kpps）实时显示在任务列表、任务详情与输出页。
  • 任务详情页的进度条也会按 masscan 的真实进度推进，而不是固定百分比。
  • 任务详情的「状态」徽标、阶段胶囊、当前阶段、扫描摘要与操作按钮都跟着任务状态实时变化（SSE 推送 + 自适应轮询：进行中 2 秒、空闲 12 秒），开始扫描后不会再停留在「等待」。
  • 进度卡片右上角的文字状态直接由最新快照推导：等待开始 → 正在启动扫描 → 正在执行：端口扫描 → 扫描完成（暂停 / 取消 / 失败各有对应文案），不会出现"已经扫到资产存活、还写着等待开始"的错位。
  • 页头右侧的绿点表示自动刷新在生效，并显示最近一次同步时间；手动点页头的「刷新」按钮可立即对齐一次。从任务列表进入详情、标签页切回前台、浏览器前进后退（含 bfcache 恢复）都会立刻按最新数据重载。
  • 扫描目标与端口范围这类可能很长的内容会在详情卡片里自动回缩为两行，点「展开全部」查看完整内容，再次点击「收起」。
  • nmap 阶段（存活探测 / 服务识别 / Nmap端口扫描）nmap 本身不输出实时百分比，进度条会显示为流动的「扫描中…」状态，并持续显示已耗时；masscan 阶段则显示精确百分比与预计剩余时间。
  • 任务已结束（完成 / 失败 / 取消）后，阶段胶囊会标绿（完成）或标红（停在该阶段），可直接查看结果或导出。

暂停 / 继续 / 取消与结果存档

  • 暂停：中断当前 nmap/masscan 进程，记录断点（存活主机、端口扫描输出、已完成服务识别的主机）。暂停请求会等到扫描进程真正退出后才返回，避免"刚暂停就点继续"报错。
  • 继续：从断点续跑，已完成的阶段与已完成服务识别的主机会跳过。
  • 端口扫描阶段（masscan 无 checkpoint）不支持精确断点：继续时会重新执行该阶段，但已发现的端口会保留，界面会给出提示。
  • 取消：终止任务，已扫描的数据全部保留（含端口扫描阶段中断时已发现的端口），可在"结果"页导出。
  • 导出：任意状态（运行中/暂停/取消/失败/完成）都可导出：XLSX、CSV、JSON，或"过程存档 ZIP"（结果 + 存活主机 + 原始 XML/端口输出 + 命令记录 + 过程日志 + README）。
  • 重新扫描或删除任务前，系统会自动把当轮结果存档到 ./ExportResults/history/，避免误操作丢数据。
  • 已完成的任务在任务列表与详情页都可点「重新扫描」，会清空结果并从头执行（旧结果已自动存档）。

注意事项

  • 扫描内网时，请确保有合法授权。未经授权的扫描可能违反相关法律法规。
  • Masscan 需要 root 权限；以普通用户运行时端口扫描会失败，可用「Nmap 端口扫描」模式替代（会自动退化为 -sT）。
  • Masscan 的高速扫描可能被网络设备检测并拦截，必要时降低扫描速率（--rate）。
  • 扫描结果保存在 ./Data_folder/ 下的 SQLite 数据库；导出与存档文件位于 ./ExportResults/。
  • 默认监听端口为 8080，可通过 -p 参数，在平台启动时修改。
  • 默认管理员账号：admin，密码：admin123，登录后请立即修改密码（新密码至少 8 位，弱口令会被拒绝）。
  • 登录会话保存在数据库中，服务重启后无需重新登录；修改密码会使其它设备的会话立即失效。
  • 扫描目标必须为 IP / CIDR / 域名 / IP:端口 形式；以 - 开头的字符串会被拒绝（防止被当成工具参数）。
  • 端口填写非法（例如 abc、99999）会直接报错，不会被静默替换为 1-65535。
