文档说明

平台简介

星云罗盘 - 资产测绘平台（NebulaCompass）是一款用于内外网资产探测和端口扫描的工具。它集成了 nmap 和 masscan 两款经典网络扫描工具，提供完整的存活探测、端口扫描和服务识别能力。

平台支持多种扫描模式，包括：全套扫描、存活探测、端口扫描、服务识别以及 Nmap 端口扫描，覆盖从资产发现到服务识别全流程。

配套工具说明

本平台依赖 nmap 和 masscan 两个外部工具来完成扫描任务。以下是如何获取和安装这两个工具的详细说明。

Nmap

Nmap（Network Mapper）是一个开源的网络探测和安全审计工具。本平台使用它进行主机存活探测（Ping扫描）和服务版本识别。

下载地址

⭐ 官网下载 📦 所有版本

官网提供 Windows、macOS、Linux 各平台的安装包和源码。

安装方式

Windows:

  • 从官网下载 nmap-7.95-setup.exe 安装包，双击安装即可
  • 安装完成后默认路径为 C:\Program Files (x86)\Nmap\nmap.exe
  • 安装程序会自动将 nmap 添加到系统 PATH

macOS:

# 使用 Homebrew 安装（推荐）
brew install nmap

# 或从官网下载 .dmg 安装包手动安装

Linux (Debian/Ubuntu):

sudo apt update
sudo apt install nmap -y

Linux (CentOS/RHEL):

sudo yum install nmap -y

从源码编译:

# 下载源码
wget https://nmap.org/dist/nmap-7.95.tar.bz2
tar jxvf nmap-7.95.tar.bz2
cd nmap-7.95

# 编译安装
./configure
make -j$(nproc)
sudo make install

编译依赖：需要安装 gcc、make、openssl-dev 等开发工具包。

Masscan

Masscan 是一款高速端口扫描器，号称"最快的互联网端口扫描器"。本平台使用它进行大规模端口扫描，利用其高速扫描能力快速发现开放端口。

下载地址

⭐ GitHub 项目 📦 Release 页面

安装方式

macOS:

# 使用 Homebrew 安装（推荐）
brew install masscan

Linux (Debian/Ubuntu):

sudo apt update
sudo apt install masscan -y

从源码编译（推荐，获取最新版本）：

# 克隆源码
git clone https://github.com/robertdavidgraham/masscan.git
cd masscan

# 编译（使用 make 即可，无需 configure）
make -j$(nproc)

# 安装到系统（可选）
sudo make install

# 如果不安装到系统，可以直接使用当前目录下的 ./bin/masscan
./bin/masscan --help

Masscan 的编译非常简单，只需要 gcc 和 make 即可，没有额外的依赖库。编译完成后，可执行文件在 bin/masscan。

Windows:

  • Masscan 主要面向 Linux/macOS，Windows 上可以：
  • 使用 WSL（Windows Subsystem for Linux） 在 Linux 子系统中编译使用
  • 或在 Cygwin/MSYS2 环境中编译

使用 w64devkit 编译（推荐 Windows 用户）：

如果没有安装编译环境，可以使用 w64devkit 工具进行编译。w64devkit 是一个面向 Windows 的便携式 C/C++ 开发工具包，内含 gcc、make 等编译工具，无需额外安装 Visual Studio 或 MinGW。

# 1. 下载 w64devkit
# 访问 https://github.com/skeeto/w64devkit/releases
# 下载 w64devkit-x.x.x-x.x.x.zip 并解压到任意目录

# 2. 进入解压后的目录，运行 w64devkit.exe 打开命令行环境
# 该环境已自动配置好 gcc、make 等编译工具
w64devkit.exe

# 3. 在命令行中编译 masscan
git clone https://github.com/robertdavidgraham/masscan.git
cd masscan
make -j4

# 4. 编译完成后，可执行文件在 bin/masscan.exe
ls -la bin/masscan.exe

编译完成后，将 bin/masscan.exe 的路径填写到平台的"系统设置"页面的"Masscan 路径"中即可。

工具验证

安装完成后，建议在系统终端中验证工具是否可以正常使用：

# 验证 nmap
nmap --version

# 验证 masscan
masscan --version

如果以上命令可以正常输出版本信息，说明工具已正确安装并添加到系统 PATH 中。然后在平台的"系统设置"页面中，分别填入工具路径即可（如果已配置系统 PATH，填入工具名即可，如 nmap 或 masscan）。

设置页面中，填入路径后点击"验证"按钮，平台会自动检查路径是否正确。

扫描模式说明

  • 全套扫描 - 进行完整的扫描流程：Ping存活探测 → Masscan端口扫描 → Nmap服务版本识别。最全面的扫描模式。
  • 存活探测 - 仅通过 Ping 扫描（nmap -sn）探测目标网段中在线的主机，不进行端口扫描。
  • 端口扫描 - 先进行存活探测，然后对存活主机进行 Masscan 端口扫描，不进行服务识别。
  • 服务识别 - 跳过存活探测和端口扫描，直接对指定的 IP:端口 进行 Nmap 服务版本识别（nmap -sV）。
  • Nmap端口扫描 - 使用 Nmap 代替 Masscan 进行端口扫描，适合精确度要求更高的场景。

注意事项

  • 扫描内网时，请确保有合法授权。未经授权的扫描可能违反相关法律法规。
  • Masscan 的高速扫描可能被网络设备检测并拦截，必要时降低扫描速率（--rate）。
  • 扫描结果会保存在 ./Data_folder/ 目录下的 SQLite 数据库中。
  • 默认监听端口为 8080，可通过 -p 参数，在平台启动时修改。
  • 默认管理员账号：admin，密码：admin123，登录后请立即修改密码。
